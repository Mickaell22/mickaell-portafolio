## Context

I needed a tool to manage invoicing for my own business. The existing options were either too simple or too expensive. I built it from scratch, tailored exactly to what I need.

## Features

- Client management with order history
- Order creation and tracking with status
- Invoice generation with export
- Statistics dashboard with revenue and a summary by period
- Product image uploads with Cloudinary
- Soft delete on all entities — nothing is permanently removed

## Tech stack

**Backend:** FastAPI + SQLAlchemy + Alembic for migrations. PostgreSQL as the database. Cloudinary for images. JWT for authentication.

**Frontend:** React with Vite, Tailwind CSS, dark mode included.

## What I learned

Building for your own use carries a different kind of pressure — if something breaks, it affects me directly. That forces you to write more solid code and to think about real edge cases.

## Status

In production. In active use at [novamicktools.com](https://novamicktools.com).
