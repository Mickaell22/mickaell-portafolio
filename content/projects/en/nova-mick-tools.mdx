## Context

I needed specific tools for my workflow at university that either didn't exist or whose available alternatives didn't fit what I needed. I built them myself, and I still use them.

## Project evolution

**Phase 1 — NovaMickTools (C# / .NET):**
Desktop application with an academic document creator, a task organizer and a PDF converter. First working version, in active use.

**Phase 2 — NovaMickTools 2.0 (Python):**
Rewritten in Python to make it cross-platform and easier to extend. Same core features with workflow improvements.

**Phase 3 — NovaMickToolsAndroid (Kotlin):**
Mobile version for Android. The tools I use most day to day, available from the phone.

## Why it matters

It's not an academic project nor a project for a client. It's a tool I built because I needed it and that evolves as my needs change. Three different languages for the same idea show how I made different technical decisions depending on the context.

## Status

In daily use. Each phase remains active on its corresponding platform.
