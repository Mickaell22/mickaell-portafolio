## Contexto

Cliente real — centro de terapia y educación especial que gestionaba todo en papel y hojas de cálculo. El proyecto fue en dos fases: primero un sistema básico, luego una expansión completa del sistema.

## Alcance

El sistema cubre la operación completa del centro:

- **Pacientes:** registro, historial, documentos, tutores, pausas de tratamiento
- **Módulo terapéutico:** sesiones, cronogramas, asistencia, estadísticas por terapeuta
- **Módulo pedagógico:** sesiones pedagógicas, evaluaciones, cronogramas, asistencia
- **Personal:** terapeutas, pedagogos, especialidades, documentos
- **Usuarios y roles:** administrador, terapeuta, pedagogo — cada uno ve solo lo suyo
- **Reportes:** generación de PDF con historial y estadísticas
- **Chat interno:** mensajería entre el personal del centro
- **Notificaciones:** sistema de notificaciones en tiempo real

## Tamaño del proyecto

190+ componentes en el frontend. El mayor proyecto en líneas de código que he entregado.

## Stack técnico

**Frontend:** React con Material UI, Vite, Redux Toolkit, hooks personalizados por entidad. Rutas protegidas por rol. Tema personalizable desde el backend (nombre del centro, colores, configuración general).

**Backend:** Python con API REST. PostgreSQL. Deploy en Railway.

## Lo que aprendí

Gestionar un proyecto de esta escala con un cliente no técnico requiere documentar decisiones constantemente. También aprendí que los sistemas de salud tienen requerimientos de privacidad que cambian todo el diseño desde el inicio.

## Estado

Entregado. En uso activo por el centro.
