## Contexto

Cliente real — tienda de flores preservadas que necesitaba un e-commerce completo con facturación electrónica válida para Ecuador. La integración con el SRI fue el núcleo técnico del proyecto.

## Facturación electrónica SRI

El sistema genera facturas electrónicas válidas para el Servicio de Rentas Internas de Ecuador. El flujo completo:

1. Generación del XML con la estructura requerida por el SRI
2. Firma digital del documento con certificado electrónico
3. Envío via SOAP al webservice del SRI
4. Recepción y almacenamiento de la autorización

Esto no es una integración de API REST moderna — el SRI usa SOAP y XML con un esquema específico que muy pocos desarrolladores juniors conocen.

## Funcionalidades del e-commerce

- Catálogo de productos con imágenes y categorías
- Carrito y proceso de compra
- Roles: ADMIN / VENDEDOR / CLIENTE
- Panel de administración con gestión de inventario
- Historial de pedidos y facturas por cliente

## Seguridad

Rate limiting, Helmet para cabeceras HTTP, sanitización de inputs. No fue un proyecto académico — manejó datos reales de clientes.

## Stack técnico

**Backend:** Node.js + Express + Prisma ORM + PostgreSQL. JWT para autenticación.

**Frontend:** React con Tailwind CSS.

## Por qué diferencia

La integración con el SRI ecuatoriano es un nicho técnico muy específico. La mayoría de desarrolladores con años de experiencia en Ecuador nunca la han implementado. En una entrevista con una empresa ecuatoriana, esto abre conversaciones diferentes.
