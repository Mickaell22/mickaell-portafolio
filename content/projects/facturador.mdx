## Contexto

Necesitaba una herramienta para gestionar la facturación de mi propio negocio. Las opciones existentes eran o demasiado simples o demasiado caras. Lo construí desde cero ajustado exactamente a lo que necesito.

## Funcionalidades

- Gestión de clientes con historial de pedidos
- Creación y seguimiento de pedidos con estado
- Generación de facturas con exportación
- Panel de estadísticas con ingresos y resumen por período
- Subida de imágenes de productos con Cloudinary
- Soft delete en todas las entidades — nada se borra permanentemente

## Stack técnico

**Backend:** FastAPI + SQLAlchemy + Alembic para migraciones. PostgreSQL como base de datos. Cloudinary para imágenes. JWT para autenticación.

**Frontend:** React con Vite, Tailwind CSS, modo oscuro incluido.

## Lo que aprendí

Construir para uso propio tiene una presión diferente — si algo falla, me afecta a mí directamente. Eso fuerza a escribir código más sólido y a pensar en edge cases reales.
